This project is called Stoke. It's a project I've had sitting in the dust for a long time, but I finally decided to complete it for this job opportunity.

The idea behind Stoke is simple: help developers figure out what to build next by recommending projects based on their skills, interests, experience and goals.

What it does

- User sign-up and login.
- Onboarding to understand users' skills, interests and goals.
- Project recommendations based on onboarding answers.
- The Machine, which scores and ranks predefined project templates.
- Save projects and keep track of progress.
- Manage project tasks.
- Dashboard for viewing projects and activity.
- Responsive interface for mobile and desktop.

How it works

The Machine uses predefined project templates and a scoring system to rank projects based on the user's preferences. It doesn't generate new project ideas.

Built with

- HTML
- CSS
- JavaScript
- Supabase
